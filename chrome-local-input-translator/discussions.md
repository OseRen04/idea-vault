# 議事録

## 会話URL未登録

### 議題
- Chromeの入力欄をローカルLLMで自動翻訳・置換する仕組みの企画とモデル選定

### 議論内容
- ユーザーは「Chromeでユーザーが入力したテキスト内容を異言語に自動で書き換えるローカルLLMが欲しい」と要望した。
- AIはChrome拡張機能で入力欄を検出し、端末内で翻訳して文章を置き換える構成を提示した。
- AIはChromeのTranslator APIを使う案、入力停止後に翻訳する案、機密性の高い入力欄を除外する案を提案した。これらはユーザーによる採用確定ではない。
- ユーザーはHugging Face上の `pfnet/plamo-3-translate-0.8b-GGUF` のスクリーンショットを示し、このローカルLLMを採用すると明言した。
- AIはGGUFモデルのChrome内直接実行は未検証であること、初期量子化候補としてQ4_K_Mを検討できることを説明した。

### 決定事項
- Chromeで入力されたテキストを異言語に自動翻訳し、入力内容を書き換える仕組みを目指す。
- ローカル翻訳モデルに `pfnet/plamo-3-translate-0.8b-GGUF` を採用する。

### 未決定事項
- ブラウザ内でLLMを直接動かすか、端末内の別プロセスに接続するか
- 対応言語・対象サイト・入力欄・自動置換タイミング
- ローカルモデルの量子化形式と実測性能
- オフライン動作、モデルライセンス、配布方法

### 次のアクション
- 採用GGUFモデルのローカル推論方式をChrome環境で検証する。
- 日本語IMEを含む入力検出と文章置換の最小プロトタイプを実装・検証する。
- 利用者が必要とする翻訳言語と操作方法を確定する。
