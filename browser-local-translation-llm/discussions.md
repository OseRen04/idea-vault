# 議事録

## 会話URL未登録

### 議題
- スマートフォンのブラウザでローカル翻訳LLMを動作させる構想の検討

### 議論内容
- 利用者は「スマホのブラウザでローカル翻訳llmを動かしたい」と要望した。
- AIは「スマホ本体で推論する方式」と「自宅PCで推論しスマホからアクセスする方式」を比較し、前者を今回の主な検討対象として提示した。後者では端末内推論にならず、運用するサーバーが必要になる。
- AIは、ブラウザ内推論にWebGPUやWebAssemblyを利用し、Transformers.js等で翻訳専用モデルを実行する構成を提案した。
- AIは、汎用LLMを必須とせず、軽量な翻訳専用モデルも比較する方針を提案した。候補としてOPUS-MT、NLLB-200、WebLLMと小型Qwen系モデルを挙げた。
- AIは、英語→日本語テキスト翻訳をMVPとし、実機で速度・メモリ・品質・オフライン動作を評価した後に対応言語を広げる開発順序を提案した。
- WebGPU対応はOS・ブラウザ・端末に依存し、大きいモデルではメモリや保存容量が制約となることを指摘した。各モデルのライセンス・互換性・性能は採用前の再確認が必要。
- 利用者はその後、企画のIdea Vaultへの保存を依頼した。

### 決定事項
- スマートフォンのブラウザでローカル翻訳LLMを動かす企画として記録する。
- 今回は企画保存のみを実施し、自動開発を許可・開始しない。

- 必要な言語、対象OS/ブラウザ、モデルの選定
- 翻訳精度・推論時間・ダウンロード容量の許容値
- オフライン動作とPWA化の必須度
- 商用化や公開範囲
