# 自律開発スタジオ

## 基本情報
- agent_development: denied
- 状態：構想
- 優先度：未設定

## 概要
GitHubに保存したアイデア一覧をAIエージェントが定期的に確認し、ユーザーが開発を許可した企画を、規定の開発ワークフローに従って自律的に開発する仕組み。

ユーザーが毎回指示を出さなくても、深夜などの時間帯に要件整理・設計・実装・テスト等を進め、GitHubに成果と進捗を残す。単発の作業で終わらず、翌日以降も開発途中の企画を継続して扱えることを目指す。

## 背景・課題
アイデアの開発を進めるたびにユーザーが指示を出す負担を減らし、深夜などの時間帯も活用して、継続的に企画を形にしたい。

## 対象ユーザー
GitHubに保存した自分のアイデアについて、許可した企画の開発を継続的に進めたいユーザー。

## 解決方法
既存のAIコーディングエージェントやスケジューラーなどを組み合わせ、GitHub上の企画を確認して開発を進める方向で検討する。開発対象の順序と許可判定を通常のプログラムで扱い、AIが要件整理・設計・実装・テストを担当する構成が提案されている。実行基盤や進捗管理の具体的な方式は未決定。

## 主な機能
- GitHubに保存したアイデア一覧の定期的な確認。
- ユーザーが開発を許可した企画の選別。
- 企画の優先度に基づく開発順序の管理。
- 規定の開発ワークフローに沿った要件整理・設計・実装・テスト。
- 成果と進捗のGitHubへの記録。
- 翌日以降の開発継続。

## 技術・制約
- アイデアの保存・管理には既存のGitHub連携を利用する。
- 開発許可は `agent_development` で管理し、値は `allowed` または `denied` とする。デフォルト、設定なし、不正な値はすべて `denied` として扱う。
- 開発許可はユーザーのみが変更できる。明示的な許可なしに `allowed` へ変更しない。新規企画は必ず `denied` とする。
- 状態は `構想` / `開発中` / `完了` / `中断` とし、ユーザーの指示なく進捗を変更しない。
- 優先度は正の整数または `未設定` とする。数値が小さい企画ほど先に開発する。
- GitHub ActionsやGitHub Agentic Workflowsなどは実行基盤の候補であり、採用は確定していない。

## 未決定事項

- 優先度が未設定の場合や同じ数値の場合の開発順序。
